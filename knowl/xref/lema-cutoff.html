Lema 43. Funções "cut-off".

Dados \(r_1< r_2\in\R\) existe uma função suave \(h\colon\R\to\R\) tal que \(h(x)=1\text{,}\) para \(x\leq r_1\text{,}\) \(0< h(x)< 1\text{,}\) para \(r_1< x< r_2\) e \(h(x)=0\text{,}\) para \(x\geq r_2\text{.}\)
